# sort_consult

consult -> reason -> class 순으로 수정함
1. 수정 방법 : 일치하는 것만 분류하고, 나머지는 모두 예외 처리로 분류 -> 예외 처리된 것들 중에서 공통적인 것을 찾아서 다시 분류 -> 반복
2. 목표
   1) 현재의 데이터 중에서 인입 이유, 처리 과정, 처리 결과가 동일한 것들이 5건 이상인 경우에 하나의 출력값을 만든다.
   2) 새로운 것들을 입력하면서 비슷한 것들끼리 자동으로 분류하여 5건 이상이 되면 하나의 출력값이 되게 한다.
4. 보완이 필요한 부분
   1) 획일화된 데이터 입력 방법
   2) 효율적이고 효과적인 수정 방법
5. 어려운 부분
   1) 데이터가 ---/---/---/------로 되어 있는데, 처리 과정과 처리 결과를 추출하기가 어렵다.
   2) 데이터 입력 방법들이 바뀌다보니, 획일화되어 있지 않아, 예외 처리가 너무 많다.(1/3)
